## 0. How to use this package

This exists so you approve the whole foundation **once** instead of a dozen times. Read §1 (the ask) and §10 (the approval sheet); the middle sections are the backing detail if you want it.

- **Each item is Approve / Hold / Amend.** Default recommendation is given for every item.
